Jira 연결 설정 필요

Jira API에 연결하려면 다음 환경 변수를 설정해주세요:

  • JIRA_BASE_URL - Jira 인스턴스 URL (예: https://your-domain.atlassian.net)
  • JIRA_EMAIL - Jira 계정 이메일
  • JIRA_API_TOKEN - Jira API 토큰

API 토큰은 Atlassian 계정 설정에서 생성할 수 있습니다.
